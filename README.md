# Управление базой данных
## Команды управления базой данных
### Система поддерживает следующие команды для работы с таблицами:

1. Создание таблицы
```bash
>>> create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...
```
Пример: create_table users name:str age:int
2. Удаление таблицы
```bash
>>> drop_table <имя_таблицы>
```
Пример: drop_table users
3. Просмотр списка таблиц
```bash
>>> list_tables
```
4. Справочная информация
```bash
>>> help
```
5. Выход из программы
```bash
>>> exit
```

### Особенности работы
* Каждая таблица автоматически получает столбец **ID:int**
* Поддерживаемые типы данных: **int**, **str**, **bool**
* Метаданные хранятся в файле **db_meta.json**
* Проверка уникальности имени таблицы при создании
* Проверка существования таблицы при удалении

## Управление данными (CRUD-операции)
### Система поддерживает следующие команды для работы с записями:

1. Добавление записи
```bash
>>> insert into <имя_таблицы> values (<значение1>, <значение2>, ...)
```
Пример: insert into users values ("Sergei", 28, true)

2. всех записей
```bash
>>> select from <имя_таблицы>
```
Пример: select from users

3. Чтение записей по условию
```bash
>>> select from <имя_таблицы> where <столбец> = <значение>
```
Пример: select from users where age = 28

4. Обновление записей
```bash
>>> update <имя_таблицы> set <столбец> = <новое_значение> where <столбец_условия> = <значение_условия>
```
Пример: update users set age = 29 where name = "Sergei"

5. Удаление записей
```bash
>>> delete from <имя_таблицы> where <столбец> = <значение>
```
Пример: delete from users where ID = 1

6. Информация о таблице
```bash
>>> info <имя_таблицы>
```
Пример: info users
    
## Декораторы

Для обработки ошибок, подтверждения опасных операций и оптимизации используются
декораторы Python. Декораторы обертывают функции движка, добавляя единообразное
поведение без дублирования кода в каждой команде.

### Обработка ошибок
1. Декоратор `handle_db_errors` перехватывает типовые исключения операций с БД
и выводит понятное сообщение вместо падения программы:
* `KeyError` — таблица или запись не найдены
* `ValueError` — некорректные данные (неверный тип, неверное количество значений, нарушение синтаксиса)
* `FileNotFoundError` — файл базы данных не найден

```bash
@handle_db_errors
def insert(metadata, table_name, values):
    ...
```
2. Декоратор-фабрика `confirm_action(action_name)` запрашивает подтверждение пользователя перед необратимыми действиями — удалением таблиц (`drop_table`) и записей (`delete`). При ответе, отличном от `y`, операция отменяется и функция не вызывается.

```bash
@confirm_action("удаление таблицы")
def drop_table(metadata, table_name):
    ...
```
3. Замер времени выполнения
Декоратор `log_time` печатает время выполнения функции — полезно для отладки и оценки производительности операций.

4. Кэширование через замыкание
Функция `create_cacher` возвращает функцию `cache_result(key, value_func)` с кэшем в замыкании: при повторном запросе с тем же key значение не вычисляется заново, а берется из кэша. В комплекте — функция `clear()` для сброса кэша.

## Установка и запуск

1. Склонируйте репозиторий и перейдите в папку проекта:
```bash
git clone https://github.com/okksy4/project-2_Abramova_M26-555.git <локальная папка>
cd <локальная папка>
```
2. Создайте виртуальное окружение и установите зависимости:
```bash
uv sync
```
3. Запустите базу данных:
```bash
uv run database
``` 
    
## Требования к системе:
* Python 3.12+
* uv для сборки пакета
