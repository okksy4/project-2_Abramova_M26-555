# Управление базой данных
## Команды управления базой данных
### Система поддерживает следующие команды для работы с таблицами:

1. Создание таблицы
```bash
>>> create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...
```
Пример: create_table users name:str age:int
2. Удаление таблицы
```bash
>>> drop_table <имя_таблицы>
```
Пример: drop_table users
3. Просмотр списка таблиц
```bash
>>> list_tables
```
4. Справочная информация
```bash
>>> help
```
5. Выход из программы
```bash
>>> exit
```

### Особенности работы
* Каждая таблица автоматически получает столбец **ID:int**
* Поддерживаемые типы данных: **int**, **str**, **bool**
* Метаданные хранятся в файле **db_meta.json**
* Проверка уникальности имени таблицы при создании
* Проверка существования таблицы при удалении

## Управление данными (CRUD-операции)
### Система поддерживает следующие команды для работы с записями:

1. Добавление записи
```bash
>>> insert into <имя_таблицы> values (<значение1>, <значение2>, ...)
```
Пример: insert into users values ("Sergei", 28, true)

2. всех записей
```bash
>>> select from <имя_таблицы>
```
Пример: select from users

3. Чтение записей по условию
```bash
>>> select from <имя_таблицы> where <столбец> = <значение>
```
Пример: select from users where age = 28

4. Обновление записей
```bash
>>> update <имя_таблицы> set <столбец> = <новое_значение> where <столбец_условия> = <значение_условия>
```
Пример: update users set age = 29 where name = "Sergei"

5. Удаление записей
```bash
>>> delete from <имя_таблицы> where <столбец> = <значение>
```
Пример: delete from users where ID = 1

6. Информация о таблице
```bash
>>> info <имя_таблицы>
```
Пример: info users

## Установка и запуск

1. Склонируйте репозиторий и перейдите в папку проекта:
```bash
git clone https://github.com/okksy4/project-2_Abramova_M26-555.git
cd project-2_Abramova_M26-555
```
2. Создайте виртуальное окружение и установите зависимости:
```bash
uv sync
```
3. Соберите пакет:
```bash
uv build
```
В папке dist/ появится wheel-файл пакета.

4. Установите пакет из собранного файла:
```bash
uv pip install dist/*.whl
```
5. Запустите базу данных:
```bash
uv run database
``` 
    
## Требования к системе:
* Python 3.12+
* uv для сборки пакета

## Примечания
Перед удалением таблицы убедитесь в отсутствии важных данных    
При создании таблицы указывайте корректные типы данных    
Используйте команду help для получения актуальной справки    
При ошибках создания таблицы проверяйте:
* Уникальность имени
* Корректность типов данных
* Правильность синтаксиса
