# Управление таблицами
## Команды управления базой данных
### Система поддерживает следующие команды для работы с таблицами:

Создание таблицы
create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...
Пример: create_table users name:str age:int

Удаление таблицы
drop_table <имя_таблицы>
Пример: drop_table users

Просмотр списка таблиц
list_tables

Справочная информация
help

Выход из программы
exit

Пример использования
>>> create_table users name:str age:int
Таблица users успешно создана

>>> list_tables
Список таблиц:
- users

>>> drop_table users
Таблица users успешно удалена

>>> list_tables

# Особенности работы
Каждая таблица автоматически получает столбец ID:int
Поддерживаемые типы данных: int, str, bool
Все метаданные хранятся в файле db_meta.json
При создании таблицы проверяется уникальность имени
При удалении таблицы проверяется её существование

# Установка и запуск
Установите пакет через pip

pip install primitive_db

Запустите базу данных
database

Требования к системе
Python 3.11+

Установленный пакет primitive_db
